# `@polydeukes/adapter-git`

[English](./adapter-git.md) · **한국어**

> **커밋 표면의 번역기**입니다. 스테이징된 diff가 약속(covenant) 입력 IR이 되고,
> `adapters.git` 설정 네임스페이스가 여기서 정의됩니다.
>
> 알파입니다. 우산의 전이 의존이라서 설치하지도 불러오지도 않습니다. 커밋 표면은
> [`pdks covenant check`](./polydeukes.ko.md#pdks-covenant-check)를 통해 닿습니다.

## 이 패키지가 소유하는 것

git의 어휘가 번역돼 사라지는 경계입니다. 스테이징된 diff가 세션 표면이 만드는 것과 같은
에이전트 중립 입력 IR이 됩니다. AI든 사람이든 같은 판정을 받습니다.

| 단위 | 하는 일 |
|---|---|
| 스테이징 변경 수집 | 스테이징 영역을 내용 기준선을 갖춘 변경 목록으로 읽습니다 |
| 순수 번역 | 그 변경들을 `CovenantInput` 하나로 접습니다 |
| 설정 어휘 | 이 어댑터 자신의 설정 네임스페이스를 검증합니다 |

순수 라이브러리입니다. 스테이징된 diff의 형태를 알 뿐 설치나 훅 러너, 밸브는 알지
못합니다. pre-commit 훅에 배선하는 것은 우산이 맡는 배포 행위입니다.

## 스테이징 수집과 `adapters.git` 네임스페이스

**수집은 무엇을 믿을지에 대해 일부러 좁습니다.**

| 결정 | 이유 |
|---|---|
| `--no-renames` 강제 | 이름 변경을 삭제 더하기 추가로 판정합니다. 보호 파일의 `git mv`가 불투명한 이름 변경 항목 하나로 빠져나가면 안 됩니다 |
| `pre`는 HEAD blob, `post`는 **스테이징된** blob | 워크트리는 쓰지 않습니다. `git add` 뒤에 갈라졌을 수 있습니다 |
| 바이너리 blob은 내용을 null로 | 손실 있게 디코딩된 바이트를 싣지 않습니다 |
| 첫 커밋 이전 상태는 전부 추가로 좁힘 | 예외를 던지지 않습니다 |

번역은 변경 하나마다 도구 호출 하나를 만듭니다. 이름은 어댑터가 소유한 `staged-write`와
`staged-delete`입니다. 삭제는 언제나 증거를 답니다. 쓰기는 스테이징된 blob이 바이너리인
경우를 빼고 증거를 답니다. 그때는 견줄 텍스트가 없으므로 `fileChange` 없이 도착하고,
증명되지 않은 다른 호출과 똑같이 경로만으로 판정됩니다. **세션 컬렉션은 정직하게
비어 있습니다.** 커밋 표면에는 세션이 없고, 있는 것처럼 보이게 키를 지어내지 않습니다.

**네임스페이스는 이 어댑터 자신의 어휘입니다.** 코어는 컨테이너 형태만 검증합니다.
어댑터마다 설정 객체 하나라는 것까지이고 내용은 그대로 통과시킵니다. 그래서 어휘와 그
검증기와 기본값이 전부 여기 있습니다.

| 키 | 값 | 기본값 | 뜻 |
|---|---|---|---|
| `adapters.git.enforce` | `block` \| `advise` | `block` | 커밋 표면의 판정이 무엇을 **하는지** |
| `adapters.git.protectedPaths` | string[] | `[]` | 커밋 표면의 **가산** 보호 범위입니다. 공통 목록 위에 얹혀 판정됩니다 |

미지 키, 두 값 밖의 `enforce`, 문자열 배열이 아닌 `protectedPaths`는 각각 전체 필드
경로와 함께 즉시 실패합니다. 작성 레퍼런스는
[설정 레퍼런스의 `adapters` 절](./configuration.ko.md#adapters)입니다.

**가산 범위가 가산인 데는 이유가 있습니다.** 수위가 관측자의 것이듯 범위도 관측자의
것입니다. 여기 적힌 항목은 작업이 역사가 되는 시점에 판정되고 세션 표면은 그것을 읽지
않습니다. 저장소가 판정기 **소스**를 세션에서 편집할 수 있게 두면서도 그것을 올리는
커밋은 멈출 수 있는 이유가 이것입니다.

`enforce: advise`에서는 밸브가 구조적으로 없습니다. 판정은 `advised`로 기록되고 권고 한
줄이 stderr에 내려앉고 커밋은 진행됩니다. 느슨해지는 것은 판정뿐입니다. 판정할 수 없는
실행은 어느 수위에서도 종료 `2`로 fail-closed합니다.

## 소비자가 닿는 곳

- **설정의 `adapters.git` 블록.**
- **`pdks covenant check`를 실행하는 pre-commit 훅.** 손으로 배선하며, 훅 관리자 셋의
  수동 절차는
  [설치](../installation.ko.md#커밋-표면-혼자-개발할-때)에 있습니다.

불러오기는 없습니다.

## 선언된 한계

- **맥락족은 여기서 판정할 수 없습니다.** `requirePrecedent`는 세션 이력이 필요한데 커밋에는
  없으므로 매치된 항목은 `skipped`를 기록합니다. 항목의 결함이 아니라 이 표면의 항구적
  조건입니다.
- **커밋은 gitignore된 파일을 결코 보여주지 않습니다.** 버전 관리 밖의 것은, 빌드된 `dist`든
  생성된 훅 스크립트든, 본성상 이 표면에 보이지 않습니다. 세션 표면이 그 경로들을 공통
  목록에 싣는 이유입니다.
- **밸브에는 터미널 앞의 사람이 필요합니다.** TTY가 없으면 프롬프트도 없고 통과할 길도
  없습니다. CI 실행과 에이전트가 띄운 `git commit`이 같은 닫힌 문에 닿습니다. 무엇도
  저장되지 않으므로 한 번의 답이 나중 커밋을 덮지 않습니다.
