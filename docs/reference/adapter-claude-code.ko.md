# `@polydeukes/adapter-claude-code`

[English](./adapter-claude-code.md) · **한국어**

> **세션 표면의 번역기**입니다. PreToolUse 페이로드가 약속(covenant) 입력 IR이 되고,
> 판정기가 읽는 파일 변경 증거와 대화 기록(transcript) 통로가 함께 실립니다.
>
> 알파입니다. 우산의 전이 의존이라서 설치하지도 불러오지도 않습니다. 세션 표면은
> [`polydeukes/claude-code`](./polydeukes.ko.md#서브패스)를 통해 닿습니다.

## 이 패키지가 소유하는 것

Claude Code의 어휘가 번역돼 사라지는 경계입니다. 에이전트와 도구의 리터럴이 **여기**
사는 것은 설계입니다. 그래야 코어까지 가지 않고, 그래야 코어의 에이전트 중립성이 구호가
아니라 테스트로 확인되는 주장이 됩니다.

| 단위 | 하는 일 |
|---|---|
| 페이로드 상향 번역 | 날 PreToolUse 페이로드가 `CovenantInput`이 됩니다 |
| 가상 후상태 | 편집이 적용되면 파일이 무엇을 담을지 디스크를 건드리지 않고 계산합니다 |
| 파일 변경 증거 | 디스크 전상태와 가상 후상태를 짝지어 유니온 증거로 만듭니다 |
| 대화 기록(transcript) 제공자 | 세션 JSONL 파일을 `CanonicalTranscript`로 바꿉니다 |
| 선례 평가기 | 맥락 계열을 위한 이 어댑터 자신의 증거 어휘입니다 |
| 텔레메트리 배선 | 깔때기 전체를 몰아서 호출당 정확히 한 행이 내려앉게 합니다 |

이 패키지는 약속(covenant) 패키지를 결코 불러오지 않습니다. 디스패치 이음매는 우산이
**주입**하고, 그래서 의존은 코어를 통해 한 방향으로만 흐릅니다.

## 페이로드 번역과 세 축

**판정기에 닿는 축이 셋**이고, 실을 수 있는 증거가 서로 다릅니다.

| 축 | 싣는 것 | 결과 |
|---|---|---|
| 도구 | 증명된 `fileChange`입니다. 도구가 실행되기 전에 계산된 변형 대상입니다 | 증명된 대상만 판정합니다. 편집 **내용** 안의 보호 경로는 언급이고 통과합니다 |
| 셸 | 실행 전에는 대상을 계산할 수 없는 경우가 많은 명령줄입니다 | 계산되는 쓰기는 편집처럼 판정하고, 나머지는 추측하지 않고 기록합니다 |
| 대화 기록 | 세션 자신의 기록입니다 | 전체 경로 등가로 판정하고 보호 조상으로는 보지 않습니다 |

번역은 매 단계가 fail-closed입니다. 서브에이전트 종류를 든 `Task` 호출은 스폰으로
대응시킵니다. 분류할 수 없는 페이로드는 번역 **실패**이고, `blocked` 한 행을 기록하고
종료 `2`를 냅니다. 추측으로 물러서지 않습니다.

**증거는 계산하는 것이지 되읽는 것이 아닙니다.** 가상 후상태는 `Edit`과 `Write`,
`MultiEdit`을 메모리에서 적용합니다. 다중 편집의 순차 적용까지 포함합니다. 그래서 내용을
보는 규율(discipline)은 지금의 파일이 아니라 **제안된** 결과를 판정합니다. 후상태가
해소되지 않으면 증거를 아예 내지 않습니다. 실제 도구도 같은 편집을 거부할 것이기
때문이고, 변형이 아닌 호출에 증거를 지어내는 일은 없습니다.

**대화 기록은 사람이 친 것으로 확정된 메시지만 받아들입니다.** 증인 밸브가 사람 전용인
근거가 이것입니다. AI는 자기 증인을 합성할 수 없습니다. 읽기 실패는 빈 대화 기록이 아니라
`undefined`로 답합니다. 빈 세션은 아직 아무 말도 하지 않은 것이라 판정 대상이고, 읽을 수
없는 세션은 증거 통로 자체가 없는 것이라 건너뜁니다. 어느 쪽이든 밸브는 닫히지 열리지
않습니다.

**선례 평가기가 판정하는 키는 둘입니다.** `subagent`는 스폰 종류의 정확한 등가입니다.
종류는 패턴이 아니라 값이기 때문입니다. `tool`은 관측된 도구 이름을 정규 표현식으로
대조합니다. 이 어휘 밖의 키는 `undefined`를 반환하고, 그것이 증거를 판정할 수 없다는
신호로 컴파일러에 전해집니다. 그래서 항목은 추측으로 판정하는 대신 건너뜁니다.

## 소비자가 닿는 곳

- **생성된 훅.** 우산의 `claude-code` 서브패스를 통해 이 어댑터를 적재합니다. 패키지를
  올리면 실행되는 것이 올라가고, 훅 파일 자체는 바뀌지 않습니다.
- **`subagent`나 `tool` 증거 키를 쓰는 `requirePrecedent` 항목.**

불러오기는 없고 자기 설정 네임스페이스도 없습니다.

## 선언된 한계

- **자식 프로세스의 쓰기는 관측 밖입니다.** 이 표면이 판정하는 것은 **선언된 도구
  호출**입니다. 프로세스를 띄우고 그 프로세스가 파일을 쓰는 명령은, 테스트 러너든 빌드든,
  명령에 대해 판정되지 자식이 한 일에 대해 판정되지 않습니다. 추적되는 파일에 대해서는
  커밋 표면이 같은 지반을 덮는 두 번째 관측입니다.
- **증거는 후상태를 계산할 수 있는 곳에만 있습니다.** 변형 도구 넷이 전부 증거를 내고
  노트북도 그렇습니다. `NotebookEdit`는 셀 단위 `modify` 증거를 냅니다. 증거가 없는 것은
  이 어댑터가 해소하지 못하는 페이로드입니다. 읽을 수 없거나 파싱되지 않는 노트북, 이름을
  붙일 수 없는 셀, 알지 못하는 편집 모드가 그렇습니다.
- **증거 없는 호출은 보수적 판정으로 물러섭니다.** 증명된 대상 대신 호출의 인자를 언급
  여부로 대조합니다.
- **저장소 밖 조상은 범위 밖입니다.** 프로젝트 루트 위의 경로는 여기서 관측하지 않습니다.
  그 지반은 에이전트 자신의 거부 정책이 소유합니다.
