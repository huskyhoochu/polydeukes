# The three SDKs

All three are process clients over a standalone `pdks` with the same four verbs (covenant input,
change set, memory ingest, memory search) and one process contract: an explicit executable resolves
against the caller's cwd, otherwise the first executable `pdks` in an absolute PATH directory runs;
the root sets the child's cwd; results are closed values with an optional communication deadline.
Judgment, telemetry, and indexing stay in `pdks`.
`node scripts/verify-sdk-contract.mjs --executable <absolute-pdks>` compares all three SDKs'
observations of the shared fixture, real judgments, telemetry, and ranked searches.

## `sdk-ts` (`@polydeukes/sdk-ts`)

Four asynchronous clients — `checkCovenant`, `checkChangeSet`, `memoryIngest`, `memorySearch` —
sharing one resolver and binary transport. `src/ir.ts` and `src/memory.ts` are committed types
generated from core's two schemas; the pinned generator's `scripts/generate-types.mjs --check`
checks drift. The published package has no runtime dependencies or peers; core is a test-only
development dependency. No bin.

## `sdk-rust` (crate `polydeukes-sdk`)

`check_covenant`, `check_change_set`, `memory_ingest`, `memory_search` as synchronous functions over
one resolver and byte transport. Its optional Duration covers communication through pipe completion;
a timed-out direct child is killed and reaped. It has no `package.json`, so pnpm, turbo, and the
publish e2e suites skip it, and tests that enumerate `packages/*` take only directories carrying a
`package.json`. Types are `src/ir.rs` and `src/memory.rs`, generated by typify from
`covenant-input.schema.json` and `memory-search-output.schema.json` and committed;
`tests/ir_generated.rs` fails when either pair differs, and
`POLYDEUKES_REGEN_IR=1 cargo test --test ir_generated` rewrites both. Forgejo CI runs `cargo test`
after the build (the e2e test spawns the built `pdks`); `publish.yml`'s `publish-crate` job uploads
it through crates.io trusted publishing.

## `sdk-python` (PyPI `polydeukes-sdk`, import `polydeukes_sdk`)

Four synchronous verbs for Python 3.12+ with zero runtime dependencies and generated TypedDict types
from core's two schemas. It has no `package.json`; explicit uv steps own its checks, build, and
installed-distribution tests.
