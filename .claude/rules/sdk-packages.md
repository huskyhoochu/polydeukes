# The three SDKs

All three are process clients over a standalone `pdks` with the same three verbs (covenant input,
change set, memory search) and one process contract: an explicit executable resolves against the
caller's cwd, otherwise the first executable `pdks` in an absolute PATH directory runs; the root
sets the child's cwd; results are closed values with an optional communication deadline. Judgment
and telemetry stay in `pdks`. `node scripts/verify-sdk-contract.mjs --executable <absolute-pdks>`
compares all three SDKs' observations of the shared fixture, real judgments, telemetry, and ranked
searches. It needs `pdks-memory` beside the `--executable` path; CI runs it with the Rust
`target/debug/pdks`.

## `sdk-ts` (`@polydeukes/sdk-ts`)

Three asynchronous clients — `checkCovenant`, `checkChangeSet`, `memorySearch` — sharing one
resolver and binary transport. `src/ir.ts` and `src/memory.ts` are committed types generated from
`schema/covenant-input.schema.json` and `schema/memory-search-output.schema.json`; the pinned
generator's `scripts/generate-types.mjs --check` checks drift. The published package has no runtime
dependencies or peers. No bin.

## `sdk-rust` (crate `polydeukes-sdk`)

`check_covenant`, `check_change_set`, `memory_search` as synchronous functions over one resolver and
byte transport. Its optional Duration covers communication through pipe completion; a timed-out
direct child is killed and reaped. It has no `package.json`, so pnpm and turbo skip it. Types are
`src/ir.rs` and `src/memory.rs`, generated by typify from `covenant-input.schema.json` and
`memory-search-output.schema.json` and committed; `tests/ir_generated.rs` fails when either pair
differs, and `POLYDEUKES_REGEN_IR=1 cargo test -p polydeukes-sdk --test ir_generated` rewrites both.
It is a member of the Cargo workspace and takes its lint levels from `.cargo/config.toml` like every
member (`rust.md`). Forgejo CI runs `cargo test` after the build (the e2e test spawns the built
`pdks`); the `publish-crate` job in `publish.yml` uploads it through crates.io trusted publishing.

## `sdk-python` (PyPI `polydeukes-sdk`, import `polydeukes_sdk`)

Three synchronous verbs — `check_covenant`, `check_change_set`, `memory_search` — for Python 3.12+
with zero runtime dependencies and generated TypedDict types from
`schema/covenant-input.schema.json` and `schema/memory-search-output.schema.json`. It has no
`package.json`; explicit uv steps own its checks, build, and installed-distribution tests.
